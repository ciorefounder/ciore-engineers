# Cioré Engineering Partner Page

The live questionnaire page for Cioré engineering partners.

Live site: https://engineers.cioreofficial.com

## What is in this repository

index.html is the complete page in one file. It includes the design, the 360 phone view, the founder note, and the 10 question partner questionnaire.

## How it works

1. A partner completes the questionnaire on the page.
2. Their answers are saved to the Cioré Engineering Partner Tracker in Google Sheets.
3. Their name and email are added to the Engineering Pipeline list in EmailOctopus.
4. EmailOctopus sends the confirmation email through its automation.

No passwords, API keys, or private credentials are stored in this repository.

## How to update the page

1. Click Add file, then Upload files.
2. Drop in the new index.html. Make sure the name is exactly index.html.
3. Click Commit changes.
4. Vercel updates the live site automatically within about a minute.
